- **ACCEPT-DEFERRED — W04 KISS-005.** The `_VERB_REGISTRY` refactor is internal-only with no surface gap [4].
- **ACCEPT-DEFERRED — W10 `target_dir` -> `output_dir` wider rename.** The wider rename spans 21 files and is cosmetic polish; the schema already rejects `target_dir` [10].
- **ACCEPT-DEFERRED — W09 audit-enum gating.** Gating on `AuditVerdict` pass + minor is correct as-is because the stored field is itself an `AuditVerdict` [9].

- **MUST-FIX — W25 (appended).** Daemonless rejection across all mutating verbs: the `state_mutate` wrapper is dead code and only `state rpc` rejects today; W25 routes every mutating verb through the rejection per the authority map [5][16].
