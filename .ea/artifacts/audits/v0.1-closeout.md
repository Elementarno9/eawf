# v0.1 closeout

Retro audit report for the v0.1 phase chain (P00..P06). This document is the
shared evidence anchor for `A01-P00..A07-P06` (cf. decision `D06` —
state-CLI verbs were carved out of v0.1 and deferred to P07, so the v0.1
audits could not record verdicts at the time they closed). With the
`audit set-verdict` verb landed in P07/W01..W03, each v0.1 audit can now
point at this report and carry a `verdict=pass`.

Tagged release: `v0.1.0` (see `git tag --list 'v*'`).

## Phase-by-phase summary

### P00 — Repo bootstrap (`A01-P00`, evaluation)

Stood up the Python package skeleton, `pyproject.toml`, `uv` workflow,
pre-commit hooks (ruff + ruff-format + detect-secrets + EOF / trailing
whitespace), CI lane, and the initial `AGENTS.md`. Empty tests passing on
CI; no runtime functionality yet.

### P01 — State + store + lock + URN + IDs + validate (`A02-P01`, evaluation)

Landed the typed `State` model (Pydantic v2, `extra="forbid"`), the JSONL
store with `Envelope` (schema v1.0), the `portalocker`-backed file lock,
canonical `urn:eawf:v1:...` URN builders, the symbol-id regex set
(`H<NN>-<NN>`, `P<NN>`, etc.), and the `validate` CLI surface.
`state.json` and the `store/*.jsonl` files became the durable substrate
the rest of v0.1 builds on.

### P02 — Direct CLI commands (state-mutation core) (`A03-P02`, evaluation)

Wrapped every state-mutating evidence verb (`goal`, `outcome`,
`hypothesis`, `audit`, `incident`, `decision`, `artifact`, `backlog`)
in `state_transaction()`. Audit-evidence guard (`require_complete_audit`)
went in: `outcome set` / `hypothesis verdict` / `incident close` /
`backlog close` all refuse to land without a `--audit` of a complete
audit. Canonical exit-code envelope shape pinned.

### P03 — Init wizard + workspace + render layer (`A04-P03`, evaluation)

`eawf init` interactive wizard, project profile selection, workspace
discovery (env > `-w` > pwd-upward), and the render layer for emitting
`.claude/` artifacts (commands / skills / settings) from the typed
profile. First end-to-end "fresh repo" path.

### P04 — Skills + envelope + Claude adapter + hooks + statusline (`A05-P04`, evaluation)

The skill envelope (`SkillSpec`, `Skill`), Claude-adapter render path
(skills → `.claude/skills/...`, agents → `.claude/agents/...`), hooks
wiring (pre-tool / post-tool / session-start), and the statusline
binary. Skills became the user-facing surface for the workflow lifecycle.

### P05 — Worktree + flow resume + memory authoritative + MCP + plan show + self-apply (`A06-P05`, evaluation)

Worktree-isolated subagent spawn + cherry-pick discipline,
checkpoint-based `flow resume`, "memory authoritative" semantics for the
`MEMORY.md` index, an MCP read-only server for `state.json`,
`eawf plan show` for per-wave plans, and the self-apply path that
bootstraps the workflow into the current repo.

### P06 — v0.1 ship: spec internalization + dogfood (`A07-P06`, ship-gate)

Internalised the planning/research/wave specs as committed artifacts,
ran the v0.1 dogfood through the workflow itself, addressed pre-merge
review, opened the v0.1 release branch, cut the `v0.1.0` tag, and wrote
the v0.2 backlog (B019..B043) plus decisions D02..D06 enumerating the
v0.2 plan. P06 closed with the canonical ship-gate audit; this retro
report is the artifact that audit's verdict points at.

## Verdict rationale

Every v0.1 phase shipped its declared scope, every PR merged via rebase
(decision `D07`), CI was green at each phase close, and the v0.1.0 tag
was cut from a clean tree. No incident was opened during v0.1. The
retro verdict for each `A0N-P0M` audit is therefore `pass`.
