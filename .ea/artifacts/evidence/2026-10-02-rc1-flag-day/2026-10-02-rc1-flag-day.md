# Flag-day canary evidence for 0.7.0rc1

## Summary

This directory holds the evidence the `REL-0.7.0rc1` flag-day rung is opened on. It carries the release's native-canary export [1], read by the `provider` and `membership` readiness rows through the evidence reader [4], and the acceptance walk the export's Milestone row was recorded from [2].

The export follows the dev5 pattern [5]. The `certifications`, `advertised`, `run_logs` and `isolation` fields are copied unchanged from the dev5 export, which carried them forward from dev3: `claude-code` 2.1.274 on `macos` / `aarch64`, certified 2026-09-18 and expiring 2026-12-17. No runtime was probed for this directory. `claude-code-driver-manifest.json` [3] is a byte-for-byte copy, so the recorded digest can be recomputed here. The acceptance walk was re-recorded on 2026-10-02 on a disposable canary under project code `W37CANARY`, and its Milestone reference is the membership bundle an rc1 create names: `eawf://WSP-W37CANARY/PRJ-W37CANARY/REP-W37CANARY/milestone/MLS-0001#MAB-0001-MLS-0001`.

No canary-window receipt file is committed here. The `flag_day` profile carries the seven `product_canary` gates as pinned proof commands and adds `epoch1_refusal` [6], but only a `product_canary` rung is refused at create for a missing pre-merge receipt.
